# Mia 业务验收测试用例

> 文档定位：面向产品验收、手工测试和回归测试的业务用例库。  
> 编制基线：`docs/mia-feature-scope.md`、`docs/menu-guides/` 及各模块需求/技术方案。  
> 基线日期：2026-10-26。若文档与实际产品行为冲突，应先确认版本与实施状态，再判断缺陷。

## 1. 测试范围

本用例覆盖 Mia 当前业务主链路：

- 登录、会话、平台账号治理。
- 项目空间创建、成员角色、资源归属和跨空间隔离。
- 模型供应商、Chat/Embedding 模型和默认模型。
- Agent 创建、配置、知识库/工具/Workflow 绑定、发布与停用。
- 知识库、文档处理、混合检索和来源引用。
- 内部 Chat、会话历史、附件、流式输出、停止与断线恢复。
- HTTP Tool、MCP Client、Skill 管理、Workflow 与 Workflow 应用。
- 公开 WebApp、Service API、Widget。
- 请求日志、Run Trace、失败诊断和敏感信息保护。

以下能力不纳入本轮验收：

- Mia 作为 MCP Server 对外发布。
- Skill 与 Agent 的完整绑定、Runtime 注入和 Trace（当前能力总览标记为待实施）。
- 图像生成、语音、插件市场、计费、复杂 RBAC 和跨空间资源共享。
- 路线图中尚未落地的 Memory、异步 Agent Task、Subagent 和声明式 Hook。

## 2. 优先级与通过标准

| 优先级 | 含义 | 执行要求 |
| --- | --- | --- |
| P0 | 阻断核心业务、安全或数据隔离 | 每次发布必须全部执行并通过 |
| P1 | 重要业务、异常恢复或管理能力 | 功能发布和完整回归必须执行 |
| P2 | 易用性、兼容性和增强体验 | 时间允许时执行，版本验收前应覆盖 |

判定原则：

- **通过**：实际结果与预期一致，且没有产生额外数据、越权或敏感信息泄漏。
- **失败**：主结果不一致，或虽然页面提示正确但后台仍产生了错误副作用。
- **阻塞**：依赖的模型、外部服务、部署配置或测试数据不可用，无法得出结论。
- 涉及 SSE、工具、Workflow 的用例除页面结果外，还应抽查同一 `request_id/run_id` 的日志与 Trace。

## 3. 测试角色与基础数据

### 3.1 测试角色

| 代号 | 身份 |
| --- | --- |
| PA | 平台 `ADMIN`，未加入空间 B |
| O1 | 空间 A 的 `OWNER` |
| M1 | 空间 A 的 `MANAGER` |
| U1 | 空间 A 的 `MEMBER`，创建部分 Agent/Tool |
| U2 | 空间 A 的 `MEMBER`，用于验证他人资源权限 |
| O2 | 空间 B 的 `OWNER` |
| V1 | 未登录的外部访问者 |

### 3.2 基础数据

| 数据 | 建议值 |
| --- | --- |
| 空间 A / B | `Mia 验收空间 A` / `Mia 隔离空间 B` |
| Chat 模型 | 一个可用的 OpenAI-compatible Chat 模型 |
| Embedding 模型 | 1536 维模型；另备 1024 维模型用于多维度测试 |
| 知识库 | `公司制度知识库` |
| 已知制度 | “试用期员工暂不享受年假；转正后每个自然年享有 5 天年假。” |
| 不存在制度 | 婚假天数（文档中不得包含） |
| HTTP Tool | 只读 `query_leave_balance`；另备一个会失败的测试端点 |
| MCP Server | 一个可信 Streamable HTTP Server，至少暴露一个只读工具 |
| Workflow | `开始 → 知识检索 → 模型 → 结束` 的制度问答流程 |

### 3.3 文件集

- 正常文件：UTF-8 TXT、Markdown、PDF、DOCX、CSV、JSON，各包含可核对的唯一事实。
- 重复文件：与正常 Markdown 字节完全相同的副本。
- 空文件、损坏 PDF、超限文件、不支持后缀文件。
- 图片附件：一张包含清晰文字的 PNG；普通附件：一个小型 TXT/PDF。

| --- | --- | --- | --- | --- | --- |

| E2E-003 | P0 | Agent 调用已绑定工具 | Agent 已绑定 `query_leave_balance` | 提问并明确给出员工号、年份，要求调用工具 | 页面展示工具调用过程；参数正确；工具结果被模型正确总结；日志链路完整 |
| E2E-004 | P0 | 发布并运行 Workflow | 制度知识库与模型可用 | 创建 RAG Workflow，校验并发布；在 Workflow 应用输入制度问题 | 应用仅运行已发布版本；按固定节点顺序执行；回答与知识一致；可查看对应 Run Trace |
| E2E-005 | P0 | 公开发布 Agent | Agent 已启用且模型可用 | O1 发布 Agent；V1 在无痕窗口打开链接并对话；O1 取消发布后再次发送 | 发布后无需工作台登录即可流式对话；取消发布后页面与 Chat API 均不可继续使用 |
| E2E-006 | P0 | 跨空间全链路隔离 | 空间 A、B 均有资源 | O2 在空间 B 尝试通过空间 A 的 Agent、Tool、知识库、日志 ID 访问资源 | 均无法读取或操作；返回 404 或等价“不存在”；响应不泄露资源名称、所属空间和配置 |
| E2E-007 | P1 | 故障可定位 | 配置一个必然返回 401/500 的 HTTP Tool | 在 Chat 触发工具失败；从聊天运行详情进入 Trace，再跳转请求日志 | 用户收到可读错误；Trace 定位到 Tool Step；请求日志显示失败类别但不暴露凭据 |
| E2E-008 | P1 | 草稿与发布版本隔离 | Workflow 已发布 v1 | 修改草稿回答文案但只保存，运行应用；再发布 v2 后重试 | 首次仍运行 v1；发布后运行 v2；v1 内容不被覆盖 |

## 5. 登录、会话与平台账号

| ID | 优先级 | 场景 | 前置条件 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- | --- | --- |
| AUTH-001 | P0 | 正确账号登录 | 有效账号 | 输入正确邮箱和密码登录 | 登录成功并进入工作台；只返回公开用户信息；长期凭证不出现在 JS 可读存储 |
| AUTH-002 | P0 | 错误凭据统一提示 | 有效账号 | 分别使用错误密码和不存在邮箱登录 | 均返回统一的未认证提示，不暴露账号是否存在 |
| AUTH-003 | P0 | 禁用账号登录 | 账号已被平台管理员禁用 | 使用正确密码登录 | 登录失败；不能进入任何空间或业务页面 |
| AUTH-004 | P0 | 未登录访问内部页面/API | 清理登录态 | 直接打开内部页面并请求内部 Agent API | 页面跳转登录；API 返回 401；无业务数据泄漏 |
| AUTH-005 | P0 | Access Token 到期自动续期 | Refresh Session 有效 | 保持页面直到 Access Token 到期后发起普通请求与 Chat | 自动刷新并重放原请求一次；用户操作不中断；不会产生重复业务请求 |
| AUTH-006 | P0 | Refresh Token 轮换防重放 | 已完成一次刷新 | 使用旧 Refresh Token 再次刷新 | 返回 401 并清理无效 Cookie；旧 Token 不可重复换取 Access Token |
| AUTH-007 | P0 | 当前设备退出 | 已登录 | 点击退出；使用原页面或原 Refresh Token 再访问 | 当前 Session 被撤销并回到登录页；重复退出幂等成功 |
| AUTH-008 | P0 | 退出全部设备 | 同一账号在两个浏览器登录 | 在设备 A 执行退出全部设备；设备 B 再刷新或请求 | 两个设备的 Refresh Session 均失效；设备 B 无法续期并回到登录页 |
| AUTH-009 | P0 | 重置密码撤销会话 | U1 在多个设备登录；PA 有账号管理权限 | PA 重置 U1 密码；U1 使用旧密码、旧会话、新密码验证 | 旧密码与旧 Session 均失效；新密码可登录 |
| AUTH-010 | P0 | 平台账号权限隔离 | 普通 USER 已登录 | 直接访问账号管理路由与接口 | 菜单不可见；路由/API 返回 403；不能查询、创建、禁用平台账号 |
| AUTH-011 | P1 | 并发 401 单飞刷新 | Access Token 即将过期 | 同时触发多个列表请求 | 只发起一次有效 Refresh；其他请求复用结果；不会因 Token 轮换互相作废 |
| AUTH-012 | P1 | 邮箱规范化与重复创建 | 已存在 `user@example.com` | 尝试创建 ` User@Example.com ` | 邮箱被 trim 并转小写；系统拒绝重复账号 |
| AUTH-013 | P1 | 首位管理员初始化保护 | 已存在可用 Admin | 再次运行初始化管理员流程 | 拒绝重复初始化；密码不出现在命令参数、日志或响应中 |

## 6. 项目空间、成员与资源权限

| ID | 优先级 | 场景 | 前置条件 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- | --- | --- |
| WS-001 | P0 | 普通用户创建项目空间 | 有效 USER 未加入任何空间 | 创建空间 A | 创建成功并自动切换；创建者成为唯一有效 OWNER |
| WS-002 | P0 | 无空间用户仍可操作账号菜单 | 用户未加入任何空间 | 登录并查看页面 | 可创建空间、查看个人账号菜单和退出；不会陷入空白页或重定向循环 |
| WS-003 | P0 | OWNER 邀请成员 | O1 在空间 A | 邀请 U1 为 MEMBER；U1 激活并登录 | 链接只激活指定账号；U1 加入空间 A 且角色正确 |
| WS-004 | P0 | 邀请链接重复使用 | 邀请已完成激活 | 再次打开同一邀请链接 | 链接不可再次激活或改变密码；提示已使用/失效 |
| WS-005 | P0 | OWNER 任命 MANAGER | U1 已是 MEMBER | O1 将 U1 改为 MANAGER；U1 重新进入空间 | U1 获得空间业务管理权限，但不会获得平台账号管理权限 |
| WS-006 | P0 | MANAGER 权限边界 | M1 已登录 | 尝试编辑空间资料、转让所有权、删除空间、邀请成员 | 不允许执行 OWNER 专属操作；后端返回 403 |
| WS-007 | P0 | MEMBER 创建并管理自己的 Agent | U1 为 MEMBER | U1 创建、编辑、发布、取消发布并删除自己的 Agent | 全部允许；资源记录正确的创建者和空间 |
| WS-008 | P0 | MEMBER 不能管理他人 Agent | U1、U2 均有 Agent | U1 编辑、发布或删除 U2 的 Agent | 同空间已知资源返回 403；原资源不变 |
| WS-009 | P0 | MEMBER 创建并管理自己的 HTTP Tool | U1 为 MEMBER | 创建普通公网 HTTPS Tool，再编辑和删除 | 允许操作自己的 Tool；列表创建者信息正确 |
| WS-010 | P0 | MEMBER 不能管理他人 Tool | U2 已创建 Tool | U1 编辑、测试敏感配置或删除该 Tool | 返回 403；凭据不回显；资源不变 |
| WS-011 | P0 | OWNER/MANAGER 管理全空间业务资源 | 空间内有 U1 创建的 Agent/Tool | O1、M1 分别编辑或停用资源 | 均允许；操作结果对空间成员生效并有审计信息 |
| WS-012 | P0 | 平台 ADMIN 不自动拥有空间权限 | PA 未加入空间 A | PA 访问空间 A 的 Agent、Tool、日志和成员 | 均被拒绝；平台 ADMIN 身份不绕过空间成员关系 |
| WS-013 | P0 | 跨空间 ID 隔离 | O1 在 A，O2 在 B | 在 B 的请求中替换为 A 的各类资源 ID | 返回 404；不暴露资源是否存在 |
| WS-014 | P0 | 切换空间清理旧状态 | U1 同时加入 A、B | 在 A 打开资源列表/编辑弹窗后切换 B | 列表、选项、缓存、请求去重和权限按钮均切换到 B；不能提交 A 的旧表单数据到 B |
| WS-015 | P0 | OWNER 转让 | O1、U1 在空间 A | O1 将所有权转让给 U1 | U1 成为唯一 OWNER；O1 按规则降级；不能出现无 OWNER 或多个有效 OWNER |
| WS-016 | P0 | 最后 OWNER 保护 | 空间仅有 O1 为 OWNER | O1 尝试退出空间或移除自己 | 在未转让/删除空间前拒绝操作，空间不会失去 OWNER |
| WS-017 | P1 | 移除成员后权限即时失效 | U1 已打开空间页面 | O1 移除 U1；U1 刷新并继续请求 | U1 无法继续访问空间数据；旧页面请求返回 404/403；其他空间不受影响 |
| WS-018 | P1 | MEMBER 私网 Tool 限制 | U1 为 MEMBER | 创建指向 localhost/私网且开启私网访问的 Tool | 后端拒绝；前端不展示或禁用高风险配置；已有凭据不泄露 |

| ID | 优先级 | 场景 | 前置条件 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- | --- | --- |
| KB-001 | P0 | 创建知识库 | 启用的 Embedding 模型 | 填写名称、描述并选择模型创建 | 创建成功；模型与维度记录正确；初始统计为 0 |
| KB-002 | P0 | 禁止使用 Chat 模型创建知识库 | 仅有 Chat 模型或篡改请求 | 尝试创建知识库 | 前端不可选；后端拒绝错误类型的模型 |

| KB-005 | P0 | 不支持/损坏/空文件处理 | 准备异常文件 | 上传文件并等待处理 | 不支持格式在入口被拒绝；损坏或空文件标记失败并展示可读原因；不影响其他文档 |

| KB-007 | P0 | 重复文件识别 | 正常文件已索引 | 再上传字节相同文件 | 提示重复或按规则阻止；不会重复生成可检索内容 |
