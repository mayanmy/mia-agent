# Workflow 画布新手指南

## 快速开始

1. 点击“新建 Workflow”。系统会创建“开始 → 结束”的最小流程。
2. 从左侧节点库添加模型、知识检索、工具、条件或模板节点。
3. 从节点右侧圆点拖到下一个节点左侧圆点，形成完整执行路径。
4. 点击节点，在右侧属性面板完成配置，然后保存草稿。
5. 点击“校验”，修复问题后发布版本，再到 Agent 配置中绑定该 Workflow 版本。

## 画布操作

| 操作     | 方法                                           |
| -------- | ---------------------------------------------- |
| 添加节点 | 点击左侧节点库中的节点按钮                     |
| 移动节点 | 按住节点卡片并拖动                             |
| 连接节点 | 从右侧输出圆点拖到下一个节点左侧输入圆点       |
| 编辑节点 | 点击节点，在右侧属性面板修改配置               |
| 删除节点 | 选中节点后点击属性面板右上角的删除按钮         |
| 删除连线 | 点击连线使其变蓝，再按 `Delete` 或 `Backspace` |
| 缩放画布 | 使用鼠标滚轮或画布左下角的缩放控件             |

## 节点说明

- **开始**：定义 Workflow 输入，每个流程只能有一个。
- **模型**：调用 Chat 模型生成文本或 JSON。
- **知识检索**：从一个或多个知识库检索上下文。
- **工具**：调用内置工具或管理员配置的 HTTP Tool。
- **条件**：按规则选择一个分支继续执行。
- **模板**：将输入和上游节点输出组合成新文本。
- **结束**：定义最终回答和结构化输出，流程至少需要一个。

条件节点的完整配置方法见 [条件分支配置指南](./workflow-condition-branch-guide.md)。

## 变量引用

配置字段支持双花括号变量：

```text
{{input.query}}
{{nodes.search.output.chunks}}
问题：{{input.query}}
资料：{{nodes.search.output.chunks}}
```

节点只能引用输入、运行信息和已经执行的上游节点，不能引用后续节点。

## 保存、校验和发布

- **保存**：更新可继续编辑的草稿，不影响 Agent 当前使用的版本。
- **校验**：检查执行路径、节点配置、变量引用以及模型、知识库、工具是否可用。
- **发布**：从当前草稿创建不可修改的版本，供 Agent 稳定运行。
- **Trace**：选择一次历史运行，在画布查看节点完成、失败、取消或跳过状态。

## 常见校验问题

- 所有节点必须能从开始节点到达，并最终存在通往结束节点的路径。
- 连线不能形成环，普通节点最多只能有一条出边。
- 条件节点的每个分支 Handle 只能连接一次。
- 模型、知识库和工具必须存在且处于启用状态。
- 变量只能引用输入、运行信息和已执行的上游节点。
