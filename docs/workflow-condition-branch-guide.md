# Workflow 条件分支配置指南

条件节点按照“分支规则”数组从上到下判断，命中第一条规则后停止。全部未命中时，流程使用“默认 Handle”。

## 字段说明

| 字段        | 是否必填           | 说明                                       |
| ----------- | ------------------ | ------------------------------------------ |
| `handle`    | 是                 | 分支唯一名称，同时标识条件节点右侧的连接点 |
| `left`      | 是                 | 要判断的值，可以是常量或双花括号变量       |
| `operator`  | 是                 | 比较操作符                                 |
| `right`     | 除 `exists` 外必填 | 用于比较的目标值                           |
| 默认 Handle | 是                 | 所有规则都未命中时使用的连接点名称         |

`handle` 应使用简短、稳定的英文名称，例如 `color`、`hot`、`approved`。分支 Handle 不能重复，默认 Handle 推荐使用 `default`。

## 支持的操作符

| 操作符     | 含义                           | `right` |
| ---------- | ------------------------------ | ------- |
| `exists`   | `left` 存在且不是 `null`       | 不需要  |
| `eq`       | 严格相等                       | 需要    |
| `neq`      | 严格不相等                     | 需要    |
| `contains` | 字符串包含文本，或数组包含元素 | 需要    |
| `gt`       | 大于                           | 需要    |
| `gte`      | 大于等于                       | 需要    |
| `lt`       | 小于                           | 需要    |
| `lte`      | 小于等于                       | 需要    |

注意事项：

- `eq` 和 `neq` 不会自动转换类型，数字 `30` 和字符串 `"30"` 不相等。
- `gt`、`gte`、`lt`、`lte` 两侧必须都是数字，或都是字符串。
- `exists` 只判断值是否存在且不是 `null`；空字符串仍然算存在。
- `contains` 的 `left` 必须是字符串或数组。

## 示例一：按用户问题分流

分支规则：

```json
[
  {
    "handle": "color",
    "left": "{{input.query}}",
    "operator": "contains",
    "right": "颜色"
  },
  {
    "handle": "outfit",
    "left": "{{input.query}}",
    "operator": "contains",
    "right": "穿什么"
  }
]
```

默认 Handle：

```text
default
```

条件节点右侧连接点从上到下依次为 `color`、`outfit`、`default`。因为规则按顺序执行，“今天穿什么颜色”会先命中 `color`。

## 示例二：判断上游节点数值

```json
[
  {
    "handle": "hot",
    "left": "{{nodes.weather.output.temperature}}",
    "operator": "gte",
    "right": 30
  },
  {
    "handle": "cold",
    "left": "{{nodes.weather.output.temperature}}",
    "operator": "lte",
    "right": 15
  }
]
```

`weather` 必须是条件节点之前、且当前路径一定会执行的节点 ID。

## 连接分支

1. 在“分支规则”中填写合法 JSON。
2. 点击画布空白处或离开输入框，使配置生效。
3. 条件节点右侧会按规则顺序生成连接点，默认 Handle 排在最后。
4. 把每个连接点拖到该分支需要执行的下一个节点。
5. 每个 Handle 最多连接一条出边。
6. 点击“校验”，确认所有分支最终都能到达结束节点。

## 常见错误

- **分支 handle 必须存在且唯一**：检查是否缺少 `handle` 或存在同名分支。
- **分支必须包含 left 和受支持的 operator**：检查字段拼写和操作符。
- **出边未绑定有效分支 handle**：删除旧连线，使用当前节点右侧的连接点重新连接。
- **分支最多只能有一条出边**：同一连接点不能连接两个后续节点。
- **节点引用了尚未执行的结果**：只能引用当前条件节点之前的上游节点。
