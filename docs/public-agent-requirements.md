# Agent 公开 WebApp 需求文档

## 1. 背景

Mia 当前已经支持在工作台内创建 Agent，并通过统一 Chat 页面或 Widget 使用 Agent。对于部分对外协作场景，团队希望把某个 Agent 以独立网页形式发布给外部用户访问。

独立 WebApp 发布不是开放 Mia 工作台，也不是让外部用户登录 Mia。它是为某个已配置好的 Agent 生成一个独立访问入口，外部用户打开链接后可以直接与该 Agent 对话。

## 2. 产品定义

一句话：

> Agent 公开 WebApp 是一个面向外部用户的独立聊天页面，基于 Agent 发布配置生成公开链接，并通过访问控制保护对话入口。

典型访问地址：

```text
https://mia.example.com/a/customer-support
```

后续支持自定义域名：

```text
https://support.example.com
```

## 3. 目标用户

- Mia 管理员：负责配置 Agent、开启公开发布、设置访问密码和权限。
- 内部业务人员：把公开链接发给客户、供应商、候选人或协作方。
- 外部访问者：无需 Mia 账号，通过公开链接访问指定 Agent。

## 4. 核心价值

- 降低外部用户使用门槛，无需进入 Mia 工作台。
- 一个 Agent 可以作为独立业务入口发布。
- 保留 Mia 内部配置、模型、知识库、工具调用能力。
- 通过密码、限流、停用开关降低公开暴露风险。
- 为后续自定义域名、公开访问日志和对外服务页打基础。

## 5. 功能范围

### 5.1 Agent 发布配置

在 Agent 编辑页新增「发布」配置：

- 是否开启公开访问。
- 公开访问 slug。
- 公开链接展示与复制。
- 可选访问密码。
- 公开页标题。
- 公开页描述。
- 停用公开访问。

### 5.2 独立公开页面

外部用户打开公开链接后进入独立聊天页：

- 不展示 Mia 后台侧边栏。
- 不展示 Agent 管理入口。
- 不要求 Mia 登录。
- 展示 Agent 名称、描述和聊天窗口。
- 支持 SSE 流式输出。
- 支持工具调用过程展示。
- 支持对话停止。

### 5.3 密码访问

Agent 开启访问密码后：

- 首次打开公开页时展示密码输入。
- 密码验证通过后进入聊天页。
- 密码错误时展示明确提示。
- 后续请求使用公开访问会话，不反复输入密码。

### 5.4 公开 Chat

公开页面调用单独的 Public Chat API：

- 通过 slug 定位 Agent。
- 不允许前端传任意 agentId。
- 使用 Agent 已配置的模型、Prompt、知识库和工具。
- 公开对话日志需要标记来源。

### 5.5 访问日志

系统需要记录公开访问的关键日志：

- 公开页访问。
- 密码验证成功 / 失败。
- 对话开始 / 成功 / 失败 / 取消。
- 工具调用成功 / 失败。
- 模型调用失败。

## 6. 不做什么

第一阶段不做：

- 不做完整门户站点或多页面 CMS。
- 不做公开用户注册 / 登录。
- 不做外部用户账号体系。
- 不做公开页面复杂主题编辑器。
- 不做付费、套餐和商业化能力。
- 不做公开 App 市场。
- 不做 OAuth、企业 SSO。
- 不做多租户 Workspace 隔离。

## 7. 版本拆分

### 7.1 v1：公开链接最小闭环

目标：管理员可以把一个 Agent 发布成独立链接，外部用户无需登录即可聊天。

必须做：

- Agent 发布配置表。
- Agent 编辑页「发布」Tab。
- 公开访问开关。
- 自动生成 slug。
- 公开链接复制。
- 独立路由 `/a/:slug`。
- Public Agent 配置查询接口。
- Public Chat SSE 接口。
- 公开对话来源标记。
- 基础限流。
- Agent 停用或发布停用时禁止访问。

暂不做：

- 访问密码。
- 自定义域名。
- 主题配置。
- 上传图片 / 文件。
- 公开访问统计页面。

### 7.2 v1.1：密码保护与可读错误

目标：公开链接可以加访问密码，并让外部用户看到清晰错误。

必须做：

- 访问密码设置 / 清除。
- 密码 hash 存储。
- 公开密码验证接口。
- 公开访问 token 或会话。
- 密码错误提示。
- 发布停用、Agent 停用、模型不可用、限流等错误可读。
- 公开访问日志记录密码验证结果。

### 7.3 v1.2：公开页体验增强

目标：让公开页更接近可交付的业务页面。

必须做：

- 公开页标题和描述。
- 欢迎语。
- 建议问题。
- 页面 Logo / 头像配置。
- 移动端适配。
- 对话复制。
- 回到底部按钮。
- 工具调用卡片与错误详情复用主 Chat 展示。

可选：

- 简单主题色。
- 页脚品牌展示开关。

### 7.4 v2：自定义域名

目标：支持业务方使用自己的域名访问公开 Agent。

必须做：

- custom domain 配置。
- 域名绑定表。
- 域名归属验证。
- Host 到 Agent 发布配置的解析。
- 自定义域名访问公开页。
- 域名停用 / 删除。

部署相关：

- 反向代理支持多 Host。
- DNS CNAME 指引。
- TLS 证书配置说明。

暂不做：

- 自动签发证书，除非部署方案明确支持。

### 7.5 v2.1：访问控制增强

目标：降低公开 Agent 被滥用的风险。

必须做：

- IP 维度限流。
- visitor 维度限流。
- 单日消息数限制。
- 公开访问过期时间。
- allowed origins / allowed hosts。
- 管理员一键重置 slug。

### 7.6 v3：公开运营与分析

目标：让公开 Agent 可运营、可排查、可优化。

可做：

- 公开访问统计。
- 会话列表。
- 失败原因聚合。
- 工具调用失败分析。
- 热门问题分析。
- 满意度反馈。
- 公开页多语言。
- Prompt / 页面版本记录。

## 8. 用户流程

### 8.1 管理员发布 Agent

1. 管理员进入 Agent 编辑页。
2. 打开「发布」Tab。
3. 开启公开访问。
4. 系统生成 slug 和公开链接。
5. 管理员保存配置。
6. 系统校验 Agent 已启用且模型可用。
7. 管理员复制链接并发送给外部用户。

### 8.2 外部用户访问公开 Agent

1. 用户打开公开链接。
2. 系统根据 slug 加载公开 Agent 配置。
3. 如果发布已停用，展示不可访问提示。
4. 如果需要密码，先进入密码页。
5. 用户输入消息。
6. 系统通过 Public Chat SSE 返回流式回复。
7. 对话结束后记录日志。

### 8.3 管理员停用公开访问

1. 管理员进入 Agent 发布配置。
2. 关闭公开访问。
3. 保存后公开链接立即失效。
4. 已打开页面再次发送消息时返回不可访问错误。

## 9. 配置项

| 配置项             | 阶段 | 必填 | 说明                        |
| ------------------ | ---- | ---- | --------------------------- |
| enabled            | v1   | 是   | 是否开启公开访问            |
| slug               | v1   | 是   | 公开链接唯一标识            |
| title              | v1.2 | 否   | 公开页标题，默认 Agent 名称 |
| description        | v1.2 | 否   | 公开页描述，默认 Agent 描述 |
| password           | v1.1 | 否   | 访问密码，只保存 hash       |
| welcomeMessage     | v1.2 | 否   | 欢迎语                      |
| suggestedQuestions | v1.2 | 否   | 建议问题                    |
| customDomain       | v2   | 否   | 自定义访问域名              |
| expiresAt          | v2.1 | 否   | 公开访问过期时间            |
| dailyMessageLimit  | v2.1 | 否   | 每日消息数限制              |

## 10. 业务规则

- 只有启用的 Agent 可以公开访问。
- 只有绑定有效 Chat Model 的 Agent 可以公开访问。
- 公开访问关闭后，公开页面和 Public Chat API 都不可用。
- slug 必须全局唯一。
- slug 不应该使用连续自增 ID。
- 密码只保存 hash，不保存明文。
- 公开 Chat API 不接受前端传入的 agentId。
- 公开访问必须有基础限流。
- 公开访问日志不能记录明文密码。
- 公开访问失败不能泄露内部模型 API Key、数据库错误和堆栈。

## 11. 验收标准

### 11.1 v1 验收

- 管理员可以为 Agent 开启公开访问。
- 系统自动生成可访问的公开链接。
- 外部用户打开公开链接不需要登录 Mia。
- 外部用户可以正常发送消息并收到 SSE 流式回复。
- 关闭公开访问后链接不可用。
- Agent 停用后公开链接不可用。
- Public Chat 日志能区分来源为 `public_site`。

### 11.2 v1.1 验收

- 管理员可以设置和清除访问密码。
- 未通过密码验证不能发起公开对话。
- 密码错误提示清晰。
- 密码验证通过后可以继续聊天。
- 密码不会明文存库或返回给前端。

### 11.3 v2 验收

- 管理员可以绑定自定义域名。
- 未验证域名不能启用。
- 已绑定域名可以访问对应 Agent 公开页。
- 删除域名后访问失效。
