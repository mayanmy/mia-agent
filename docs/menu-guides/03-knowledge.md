# 知识库菜单新手引导

## 一、这个页面做什么

知识库负责文档上传、解析、切分、Embedding 和向量索引，为 Agent 或 Workflow 提供 RAG 资料。

## 二、页面按钮

| 按钮 | 作用 |
| --- | --- |
| 刷新 | 更新知识库、文档数和 Chunk 数 |
| 新增知识库 | 选择 Embedding 模型并创建向量空间 |
| 编辑 | 修改名称、描述和启用状态；Embedding 配置锁定 |
| 文档 | 打开文档抽屉 |
| 上传文档 | 上传 `.txt/.md/.markdown/.pdf/.docx/.csv/.json` |
| 文档抽屉 → 刷新 | 更新索引状态 |
| 重建/重试 | 重新解析、切分和向量化 |
| 删除文档 | 删除文件和索引记录 |
| 删除知识库 | 停用并移除知识库，Agent 后续无法检索 |

## 三、创建与上传

### 操作步骤

1. 确保已有启用的 Embedding 模型。
2. 点击“新增知识库”。
3. 填写名称、选择 Embedding 模型、填写描述并启用。
4. 点击“创建”。
5. 在该行点“文档”→“上传文档”。
6. 等待状态变为“已索引”，Chunk 数大于 0。

### 可复制文档

```markdown
# 员工休假制度

## 年假
试用期员工暂不享受年假。转正后每个自然年享有 5 天年假。

## 病假
连续病假超过 2 个工作日，需要上传二级及以上医院证明。
```

```text
名称：公司制度知识库
Embedding 模型：text-embedding-3-small · 1536 维
描述：公司休假、报销和入职制度
启用：开
```

### 效果预期

状态依次经历上传、解析、切分、向量化，最终显示绿色“已索引”。

## 四、分片规则

当前页面没有分片参数输入框。默认约 1000 字符一片、重叠约 120 字符，并优先在段落或句末截断。

💡 使用标题、空行和短段落；把条件与结论放在同一段。扫描 PDF 先做 OCR，复杂表格优先转 Markdown。

## 五、绑定和测试

1. 编辑 Agent →“知识库绑定”。
2. 勾选“公司制度知识库”并保存。
3. 测试原文问题、同义问题、不存在的问题。

```text
试用期员工有几天年假？
没转正可以休年假吗？
婚假有几天？
```

预期：前两问命中；未收录的婚假问题应明确资料不足。

## 六、常见问题

- **没有 Embedding 选项**：模型类型不是 Embedding 或未启用。
- **一直处理中**：点刷新并查看错误列、后端日志和 Embedding 服务。
- **Chunk 为 0**：文档为空、解析失败或格式不适合。
- **检索不到**：检查“已索引”、知识库启用、Agent 绑定和提问关键词。
- **返回无关内容**：改善文档结构；Workflow 中降低 Top K 或提高最低分数。

⚠️ 修改文档内容、切分策略或 Embedding 配置后需要“重建”；不要仅靠重新提问期待旧向量自动改变。
