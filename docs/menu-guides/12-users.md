# 成员菜单新手引导

## 一、这个页面做什么

“成员管理”包含平台账号治理与项目空间成员治理。空间 Owner/Manager 可以邀请成员并设置 `MANAGER / MEMBER`；平台管理员负责账号状态、密码和登录会话。

## 二、页面按钮

| 按钮 | 作用 |
| --- | --- |
| 查询 | 按邮箱或名称搜索 |
| 新增成员 | 管理员直接创建账号和初始密码 |
| 邀请成员 | 生成一次邀请激活链接 |
| 保存角色 | 调整项目空间内的 Manager/Member；Owner 转让仅由 Owner 执行 |
| 重置密码 | 设置新密码 |
| 撤销会话 | 使该成员所有登录 Session 失效 |
| 复制邀请链接 | 复制创建后返回的激活地址 |

## 三、直接创建成员

### 操作步骤

1. 点击“新增成员”。
2. 填邮箱、显示名称、初始密码和角色。
3. 点击确认创建。
4. 将地址和初始密码通过安全渠道发给本人，并要求首次登录后更换。

### 示例

```text
邮箱：new.user@example.com
显示名称：新成员
空间角色：成员（MEMBER）
初始密码：使用密码管理器生成，不使用本文示例
```

### 效果预期

成员加入当前空间后可使用被授权的 Agent、Workflow 应用和对话；Owner/Manager 负责模型、工具、MCP、Skill、Workflow、运行链路、请求日志和成员治理。

## 四、邀请成员

### 操作步骤

1. 点击“邀请成员”。
2. 填写邮箱、名称和角色，点击“生成链接”。
3. 点击“复制邀请链接”。
4. 通过可信渠道发送给指定成员。
5. 成员打开 `/activate` 页面并设置密码完成激活。

### 效果预期

邀请链接只用于指定账号激活；激活后可正常登录。

## 五、角色和会话治理

- 空间角色改为 MANAGER 会获得高风险配置权限，应遵循最小权限；平台 ADMIN 是另一层账号治理权限。
- 成员离职、设备丢失或怀疑 Token 泄漏时，点击“撤销会话”。
- 忘记密码时使用“重置密码”，不要让用户共享账号。

## 六、常见问题

- **成员看不到工具/Workflow 编辑器**：MEMBER 空间权限的正常表现。
- **邀请链接打不开**：检查 Mia 公网地址、链接是否完整和邀请状态。
- **改角色后页面没变化**：让成员重新登录或撤销既有会话。
- **首位管理员无法创建**：如果已存在可用 Admin，应从成员页面管理，不要重复运行 bootstrap 脚本。

⚠️ “撤销会话”会让该成员所有设备退出。执行前确认目标账号；不要把所有日常用户都设成管理员。
