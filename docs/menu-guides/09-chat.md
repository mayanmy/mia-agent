# 对话菜单新手引导

## 一、这个页面做什么

“对话”是内部成员统一使用 Agent 的入口，支持选择 Agent、流式回答、会话历史、附件、知识检索事件和工具调用事件。

## 二、主要区域

- **Agent 选择/画廊**：选择要使用的助手。
- **会话列表**：在保留模式下创建、切换和恢复历史会话。
- **消息区**：显示用户、助手、检索和工具事件。
- **输入框**：输入问题，支持附件时可添加文件/图片。
- **发送/停止**：发送消息；生成中停止会取消上游请求。

## 三、开始第一次对话

### 操作步骤

1. 点击“对话”。
2. 从 Agent 画廊选择“公司制度助手”。
3. 输入问题并发送。
4. 观察知识检索卡片、token 流式输出和参考来源。
5. 继续追问，验证历史上下文。

### 可复制测试

```text
第一问：试用期员工有几天年假？
追问：那转正以后呢？
边界问题：婚假有几天？
工具问题：请调用计算器计算 (18+27)*3。
```

### 效果预期

第一问命中知识库，追问理解“转正”上下文，边界问题拒绝编造，工具问题显示调用卡片。

## 四、会话模式

- **单次窗口讨论**：窗口关闭后不保留历史，适合临时问题。
- **窗口可保留数据**：按成员恢复历史，适合连续业务讨论。
- `max_context_turns` 控制发送给模型的历史轮数，不等于页面能显示的全部历史。

## 五、附件建议

1. 先确认 Agent/接口允许对应文件类型和大小。
2. 附件适合当前问题的临时上下文；要长期复用，应上传知识库并索引。
3. 文件上传完成后再发送，避免消息引用未完成的附件。

## 六、常见问题

- **看不到 Agent**：Agent 未启用或账号无权限。
- **没有检索卡片**：Agent 未绑定知识库，或问题未触发检索。
- **停止后仍消耗 token**：检查反向代理断开传递和上游模型取消支持。
- **追问忘记上下文**：会话被切换、模式为单次窗口，或 max_context_turns 太小。
- **一直转圈**：检查模型连接、SSE 代理缓冲和日志/Run Trace。

⚠️ 不要在对话中粘贴 API Key、密码或无授权的个人敏感信息。对话和运行日志可能为排错而被保存。
