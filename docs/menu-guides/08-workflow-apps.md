# Workflow 应用菜单新手引导

## 一、这个页面做什么

“Workflow 应用”供成员直接运行管理员已经发布的确定性流程。这里不能编辑节点，也不能运行未发布草稿。

## 二、页面元素与按钮

| 元素 | 作用 |
| --- | --- |
| 应用卡片 | 展示名称、描述、发布版本和输入数量 |
| 版本标签 `vN` | 表示当前运行的不可变版本 |
| 运行 | 打开输入表单 |
| 执行/运行 | 提交输入并等待结果 |
| 关闭/取消 | 关闭运行弹窗 |

## 三、运行一个应用

### 操作步骤

1. 点击“Workflow 应用”。
2. 找到“公司制度 RAG 流程”，确认版本如 `v1`。
3. 点击“运行”。
4. 在 `query` 输入框填问题并提交。
5. 查看 Chat Answer、结构化输出和运行结果。

### 可复制示例

```text
query：病假三天需要提供什么材料？
```

如果输入类型是 JSON，可填：

```json
{"query":"病假三天需要提供什么材料？"}
```

### 效果预期

流程按固定顺序执行，返回“需要二级及以上医院证明”等知识库答案。

## 四、没有应用怎么办

页面显示“暂无已发布的 Workflow”时：

1. 管理员进入“Workflow”。
2. 打开流程并点击“校验”。
3. 修复错误后点击“发布”。
4. 回到“Workflow 应用”刷新页面。

## 五、常见问题

- **输入框和教程不同**：开始节点定义了不同输入，以页面实际字段为准。
- **结果还是旧逻辑**：管理员只保存了草稿，没有发布新版本。
- **运行失败**：联系管理员在 Workflow“运行记录”或 Run Trace 查看失败节点。
- **普通成员不能编辑**：这是权限设计；编辑器仅管理员可用。

💡 需要稳定执行每一步时用 Workflow 应用；需要自由对话、由模型决定是否调用能力时用 Agent/对话。
