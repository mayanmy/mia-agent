# Workflow 菜单新手引导

## 一、这个页面做什么

Workflow 是管理员的确定性流程工作室。草稿可编辑；发布版本不可变，可在“Workflow 应用”运行或绑定给 Agent。

## 二、页面与编辑器按钮

| 按钮 | 作用 |
| --- | --- |
| 新手指南 | 打开画布说明 |
| 新建 Workflow | 创建默认“开始 → 结束”草稿 |
| 打开 | 进入画布编辑器 |
| 编辑信息 | 修改名称和描述 |
| 运行 | 输入参数执行已发布版本 |
| 归档 | 从工作室可用列表移除 |
| 撤销/重做 | 回退或恢复图修改 |
| 运行记录 | 查看 Workflow 历史 Trace |
| 校验 | 检查路径、配置、变量和资源 |
| 保存 | 保存草稿，不影响当前发布版本 |
| 发布 | 保存、校验并生成不可变版本 |

## 三、节点说明

| 节点 | 用途 |
| --- | --- |
| 开始 | 定义输入变量，每个流程一个 |
| 知识检索 | 从知识库召回 chunks 和来源 |
| 模型 | 调用 Chat 模型生成文本/JSON |
| 工具 | 调用内置、HTTP 或 MCP 工具 |
| 条件 | 按规则选择分支 |
| 模板 | 拼接输入和上游输出 |
| 结束 | 定义 Chat Answer 和结构化输出 |

## 四、创建最小 RAG Workflow

### 操作步骤

1. 点击“新建 Workflow”。
2. 填名称“公司制度 RAG 流程”和描述。
3. 添加“知识检索”和“模型”节点。
4. 删除默认开始到结束的线。
5. 连接“开始 → 知识检索 → 模型 → 结束”。
6. 配置节点，保存、校验、发布。

### 配置示例

开始输入：

```text
query / string / 必填
```

知识检索：

```text
知识库：公司制度知识库
查询表达式：{{input.query}}
Top K：5
最低分数：0.2
```

模型 Prompt（将节点 ID 替换为画布真实 ID）：

```text
问题：{{input.query}}
资料：{{nodes.retrieval-abc.output.chunks}}
只能根据资料回答；资料不足时明确说明。先给结论，再给步骤和来源。
```

结束：

```text
Chat Answer：{{nodes.llm-def.output.text}}
结构化输出 answer：{{nodes.llm-def.output.text}}
```

### 效果预期

校验通过，顶部显示“已发布 v1”，“Workflow 应用”出现该流程。

## 五、画布操作

- 点击左侧节点库添加节点。
- 拖节点卡片移动。
- 从右侧输出圆点拖到下个节点左侧输入圆点连线。
- 点击节点在右侧属性面板编辑。
- 点击连线后按 Delete/Backspace 删除。
- 变量只能引用 `input`、运行信息和已执行的上游节点。

## 六、常见问题

- **节点不可达**：每个节点必须从开始可达，并最终通向结束。
- **形成环路**：Workflow 是 DAG，不允许回连。
- **变量非法**：不能引用下游节点；优先用变量选择器插入。
- **资源不可用**：模型、知识库、工具必须存在且启用。
- **发布后编辑没生效**：修改的是草稿，需再次发布新版本。
- **草稿冲突**：先“复制本地 Graph”备份，再“重新加载”。

⚠️ “保存”不会修改正在使用的发布版本；“发布”才会生成新版本。归档前确认没有业务仍依赖该流程。
