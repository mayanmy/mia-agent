# 模型供应商菜单新手引导

## 一、这个页面做什么

“模型供应商”保存上游模型服务地址、凭据和具体模型配置。Agent 需要 Chat 模型；知识库需要 Embedding 模型。

## 二、页面按钮

| 按钮 | 作用 | 结果 |
| --- | --- | --- |
| 默认模型设置 | 选择平台默认 Chat/Embedding 模型 | 新建配置优先使用默认项 |
| 刷新 | 重新读取供应商和模型状态 | 不修改数据 |
| 添加自定义供应商 | 打开供应商表单 | 可配置 OpenAI-compatible/Ollama 等服务 |
| 安装 | 保存新供应商 | 供应商卡片出现在列表 |
| 编辑 | 修改名称、Base URL、Key、启用状态 | 留空 Key 通常保留既有凭据 |
| 添加模型 | 在供应商下增加模型配置 | 可供 Agent 或知识库选择 |
| 同步模型列表 | 从上游读取可用模型 | 填充模型名称候选项 |
| 测试连接 | 调用上游验证配置 | 返回成功或具体错误 |
| 删除/卸载 | 移除供应商或模型 | 已被引用时可能失败，先解除绑定 |

## 三、创建供应商

### 操作步骤

1. 点击“模型供应商”→“添加自定义供应商”。
2. 填写名称、供应商类型、Base URL、API Key。
3. 打开“启用”，点击“安装”。

### 可复制示例

```text
名称：团队 OpenAI
供应商类型：OpenAI Compatible
Base URL：https://api.openai.com/v1
API Key：sk-替换为真实密钥
启用：开
```

### 效果预期

页面出现“团队 OpenAI”卡片，凭据只显示掩码，不回显明文。

## 四、添加 Chat 模型

### 操作步骤

1. 在供应商卡片点“添加模型”。
2. 可先点“同步模型列表”，也可手工输入名称。
3. 模型类型选“Chat”，填写上下文长度并启用。
4. 点击“添加”，随后测试连接。

### 可复制示例

```text
模型名称：gpt-4.1-mini
模型类型：Chat
模型上下文长度：128000
基础 URL：https://api.openai.com/v1
启用：开
```

### 效果预期

Agent 的“模型选择”中出现该模型。

## 五、添加 Embedding 模型

```text
模型名称：text-embedding-3-small
模型类型：Embedding
向量维度：1536
模型上下文长度：8191
基础 URL：https://api.openai.com/v1
启用：开
```

创建后进入“默认模型设置”，分别选择默认 Chat 和 Embedding 模型并保存。

### 效果预期

新建知识库时出现“text-embedding-3-small · 1536 维”。

## 六、常见问题

- **模型下拉为空**：模型类型选错或未启用。
- **同步列表失败**：上游可能不支持模型枚举，手工输入准确名称。
- **401/403**：Key 无效或没有模型权限。
- **404**：Base URL 多写/少写 `/v1`，以供应商协议为准。
- **Embedding 入库失败**：向量维度与服务真实输出不一致。

⚠️ 知识库创建后会锁定 Embedding 模型和维度。要换模型，创建新知识库并重新上传，避免同一向量空间混用不同维度。
